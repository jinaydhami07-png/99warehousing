99Warehousing PHP

Installation card

This package holds two folders. They go in different places on your account — that separation is what keeps your database password off the public web.

  • PHP7.4+
  • Extensionspdo_mysql, gd
  • DatabaseMySQL 5.7+
  • ServerApache + mod_rewrite

Where the two folders end up

Your account after unpacking, with everything in its place.

/home/youraccount/
│
├── public_html/                  ← served to the world
│   ├── index.html
│   ├── assets/
│   ├── uploads/               photos land here
│   ├── api.php
│   └── .htaccess
│
└── 99warehousing-app/            ← never reachable over HTTP
    ├── app/
    ├── bin/
    ├── config/.env            your database password
    ├── database/
    └── storage/

  1. Put the folders in place

    Upload the contents of public_html/ into your account's real public_html. Then upload 99warehousing-app/ one level above it, so the two sit side by side as shown.

    The contents — not the folder. Dragging the folder itself in gives you public_html/public_html, and every page on the site returns 404.
    ✓ public_html/index.html ✗ public_html/public_html/index.html

  2. Create the database

    In cPanel → MySQL Databases, create a database and a user, then add that user to the database with ALL PRIVILEGES. cPanel prefixes both names with your account — keep the prefixes, you need them next.

  3. Fill in the settings

    Copy 99warehousing-app/config/.env.example to config/.env and edit it. It will not run until you do. Set the four DB_ values, your domain, an admin passkey, and two different JWT secrets: 

    php -r "echo bin2hex(random_bytes(48)), PHP_EOL;"

    PUBLIC_DIR is already set correctly for the layout above. Change it only if you put the two folders somewhere else — if it is wrong, uploads appear to succeed and every photo 404s.

  4. Create the tables, then check it

    Run the installer once. With SSH, from inside 99warehousing-app/: 

    php bin/install.php

    No SSH? cPanel → Cron Jobs can run it once — then delete the cron job. Full instructions are in DEPLOY-TO-GODADDY.md.

    Then open /api/v1/health on your domain. You want "database":"connected". If you get that, load the site and register an account.
